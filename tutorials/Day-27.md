## 保姆教程

## RAG 安全审计清单（30 项）

### 输入层（8 项）
1. [ ] Prompt Injection 检测（正则+语义）
2. [ ] 输入长度限制
3. [ ] 特殊字符过滤
4. [ ] 编码攻击检测（Unicode/Base64）
5. [ ] 多语言注入检测
6. [ ] 系统提示词泄露检测
7. [ ] 角色扮演攻击检测
8. [ ] 输入日志记录

### 检索层（8 项）
9. [ ] 文档上传安全扫描
10. [ ] Embedding 异常检测
11. [ ] 向量投毒检测
12. [ ] 分块边界注入检测
13. [ ] 相似度阈值设置
14. [ ] 检索结果关键词过滤
15. [ ] 路由白名单
16. [ ] 混合检索双通道过滤

### 生成层（7 项）
17. [ ] System prompt 安全加固
18. [ ] 上下文窗口限制
19. [ ] 检索结果与查询相关性校验
20. [ ] 生成温度控制
21. [ ] Function calling 权限分级
22. [ ] 工具调用确认机制
23. [ ] 生成过程日志记录

### 输出层（7 项）
24. [ ] 敏感信息脱敏（API Key/电话/密码）
25. [ ] 输出内容安全审查
26. [ ] 幻觉检测
27. [ ] SQL/代码注入过滤
28. [ ] XSS 过滤
29. [ ] 输出日志记录
30. [ ] 用户反馈机制

## 审计报告模板
~~~markdown
# [项目名] RAG 安全审计报告
## 1. 审计范围
## 2. 检查结果汇总（通过/不通过/不适用）
## 3. 发现的风险（高/中/低）

## 5. 复测计划
~~~
